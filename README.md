# natureza-jur-dica-empresas
# Natureza Jurídica das Empresas

Projeto educativo e interativo desenvolvido no contexto de uma atividade acadêmica do Senac, com o objetivo de apresentar conceitos fundamentais sobre as naturezas jurídicas das empresas no Brasil.

## Sobre o projeto

O projeto consiste em um site educativo que reúne informações sobre diferentes modalidades jurídicas empresariais, apresentadas de maneira organizada, visual e interativa.

A proposta é facilitar a compreensão das características, diferenças e particularidades de cada modalidade, utilizando recursos de navegação e ferramentas comparativas.

## Objetivos

- Apresentar os principais conceitos relacionados à natureza jurídica das empresas.
- Explicar as características das diferentes modalidades empresariais.
- Facilitar a comparação entre estruturas jurídicas.
- Proporcionar uma experiência de aprendizagem interativa.

## Funcionalidades

- **Introdução:** apresentação dos conceitos fundamentais.
- **Modalidades:** detalhamento das principais naturezas jurídicas.
- **Comparador interativo:** comparação entre diferentes modalidades.
- **Outras formas jurídicas:** apresentação de estruturas empresariais adicionais.
- **Quiz interativo:** questões práticas com correção e explicações automáticas.

## Como executar

O projeto pode ser executado localmente:

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Navegue pelas seções e utilize as funcionalidades disponíveis.

Não é necessário instalar dependências ou configurar um servidor para a execução local.
